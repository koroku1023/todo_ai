# アプリ要求・要件定義書

## 1. 要求定義 📋

### 1.1 アプリの目的

タスクを管理するコストを削減し、ユーザーが「タスクそのもの」に集中できるようにする。

### 1.2 対象ユーザー

タスク管理をしたいが、入力や完了操作が面倒で続かない人

- 勉強、仕事、家事、日常のタスク（予定）を管理したいユーザー

### 1.3 解決したい課題（TODOアプリの現状課題）

- **操作の負担**: アプリを開き、プロジェクトを探し、階層を辿って作成・完了するステップが重い。
- **削除・完了の管理**: 終わったタスクを探して操作する手間。
- **リスケの複雑さ**: 期限変更のためにタスクを検索し、設定を書き換える手間。
- **過剰な機能**: 高機能すぎて使いこなすことが困難。

### 1.4 提供価値

- テキスト・音声でタスクの追加・完了・削除・編集を**1アクション**で実行。
- ミニマルなUI（プロジェクト > 親タスク > 子タスク、今日のタスク）。

### 1.5 ユースケース

- **一括登録（トップ画面）**: 音声やテキストで「今日やるべきこと」を話すだけで、プロジェクトを自動判別して登録。
- **プロジェクト内操作**: 特定のプロジェクト（例：買い物）の中で、関連するタスクを音声で一括登録。

### 1.6 成功指標

- 1タスクあたりの追加時間：95%ileで **10秒以内**
- 1タスクあたりの完了時間：95%ileで **10秒以内**
- 一週間継続率：**40%以上**

## 2. スコープと制約 🛠️

### 2.1 スコープ

- **対象範囲**: テキスト・音声によるタスクのCRUD（追加・完了・削除・編集）機能。
- **対象外**: リマインダー、ウィジェット、AIによるタスク検討、会話機能、カレンダー。

### 2.2 制約事項

- **リリース**: 12月
- **予算**: 開発費 30,000円 / 月額運用費 5,000円

## 3. 機能要件 📱

### 3.1 画面構成・遷移

- **全体ナビゲーション**: スワイプ操作による画面遷移。
  - （左）今日のタスク画面 ⇔ （中央）プロジェクト一覧画面 ⇔ （右）各プロジェクト詳細画面
- **共通UI**: 入力バー（テキスト・音声機能）、設定画面への導線。

### 3.2 各画面の詳細

- **今日のタスク（ホーム）**: プロジェクトごとにグルーピング表示。親 > 子の階層表示。ショートカット遷移。
- **プロジェクト一覧**: 追加、並び替え、詳細遷移。
- **プロジェクト詳細**: 階層表示（親 > 子）、折りたたみ機能、並び替え。
- **タスク操作**: 追加、編集、削除、完了、Undo機能（削除・完了の取り消し）。
- **タスク編集（ポップアップ）**:
  - **親**: タイトル、カラー設定。
  - **子（閲覧）**: タイトル、日付、開始/終了日時、メモ。
  - **子（編集）**: タイトル、日付、時間（デフォルト30分）、メモ、繰り返し設定（曜日指定）。完了時に「保存して新規追加」が可能。
- **入力インターフェース**: チャット型テキスト入力、音声入力ポップアップ。権限OFF時のフォールバック。

## 4. 非機能要件 ⚙️

### 4.1 性能・可用性

- **応答速度**: ローカル処理 p95 ≤ 500ms、外部AI呼び出し p95 ≤ 10s、起動から入力可能まで ≤ 5s。
- **信頼性**: クラッシュフリーセッション ≥ 99%、Undo（直前1件/5秒）必須。
- **データ**: SQLiteによるローカル永続化。1万タスクまでIndex高速化で対応。

### 4.2 保守性・移植性

- **開発基盤**: Expo / React Native（iOS 16+ 対象）。
- **品質管理**: CIでのLint/型チェック、主要ユニットのテスト。
- **拡張性**: 外部ライブラリはアダプタ層で抽象化し、差し替えを容易にする。

### 4.3 セキュリティ・プライバシー 🔒

- **データ保存**: MVPは端末内のみ。AI実行時のみ外部送信。
- **API管理**: APIキーはサーバー側で管理。
- **最小化**: テキスト/音声内容のみ送信。識別子や位置情報は送らない。オプトイン方式の外部送信。

### 4.4 互換性・アクセシビリティ

- **UI**: ダークモード対応、Dynamic Type対応、セーフエリア対応。
- **アクセシビリティ**: VoiceOver対応、タップ領域 44×44pt以上、コントラスト比確保。
- **バックアップ**: iCloudバックアップ対応。アプデ時のDBマイグレーション整合性。
